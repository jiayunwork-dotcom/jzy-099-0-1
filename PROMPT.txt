给计算机专业学生做一个浏览器里的最短路径算法教学看板，专注把带权图上的单源最短路这一件事讲透：既覆盖只能处理非负权的 Dijkstra，也覆盖能处理负权边、并能识别负权环的 Bellman–Ford，让学生在同一张图上把两者的执行过程与适用边界看清楚。它是前后端一体的 Web 应用，浏览器端提供图编辑与演示看板，后端负责算法计算与正确性保证。

页面主体是一块图编辑画布加一块算法演示面板。学生在画布上点击添加节点、拖拽建立有向边，双击给边标注权重（允许负值），节点可以拖动调整位置。旁边配一张邻接矩阵面板与当前图结构实时同步。学生指定源点后，选择 Dijkstra 或 Bellman–Ford 运行，看板逐步演示松弛过程：当前正在处理的边高亮，一张从源点到各节点的距离表随每一步更新，已确定最短距离的节点被标记；Dijkstra 额外展示优先队列内容的变化，Bellman–Ford 则展示按轮次对所有边的松弛，并在检测到负权环时明确高亮环上的节点、报告「存在负权环，最短路不存在」。演示支持暂停、单步、加速与减速，跑完后从源点到任一目标节点的最短路径整条高亮，并显示路径总权重。

正确性是这个看板的主线，要由后端守住：图中没有负权边时，Dijkstra 与 Bellman–Ford 给出的各节点最短距离必须完全一致；把某条边的权重调大，任一节点的最短距离都不会减小；源点到自身距离恒为零；从源点不可达的节点其距离标记为无穷大；一旦从源点可达的范围内存在负权环，就不能返回一个有限的最短距离，而要如实报告负权环。Dijkstra 遇到负权边时应当拒绝或明确警告其结果不可信，而不是悄悄给出一个错误的距离。要内置几张经典图（含一张带负权但无负权环、一张含负权环）供学生一键载入对照。

后端负责全部算法：Dijkstra、Bellman–Ford、负权环检测以及最短路径回溯都在后端计算，把逐步的中间状态（距离表快照、被松弛的边、队列或轮次信息）返回给前端驱动动画，前端只负责渲染与交互，不自己重算一套。非法输入（引用不存在的节点、对 Dijkstra 传入负权等）由后端给出带原因的响应。

前端用 React 加 TypeScript、Vite 构建，画布与看板可用 SVG 或 Canvas 绘制；后端选 Python 3.12 加 FastAPI 承载算法接口。工程按职责拆成一组模块文件：前端侧画布、邻接矩阵、距离表、演示控制分别独立成组件，后端侧图模型、Dijkstra、Bellman–Ford、负权环检测、路径回溯分别独立成模块，不要把算法凝在单个大文件里。整套东西用一份 Docker 配置一次构建，起容器后页面与接口一并对外可达；仓库里要带上自动化测试，把「无负权时两种算法给出的距离一致」和「存在负权环时被如实识别」这两条主线钉住。
